----------------------------------------------------------------
  四、通用性验证：JDBCTool 不依赖任何具体实体类
----------------------------------------------------------------
    实体类的表名 / 字段名 / 主键全部来自注解：
      Student -> 表 student，主键 id
      College -> 表 college，主键 id
    新增实体类时，只要按同样规则加注解，无需修改 JDBCTool 一行代码。
